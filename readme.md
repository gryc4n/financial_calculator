# FinCal

FinCal is a financial dashboard and calculator application built with HTML, CSS and Vanilla JavaScript.

The project is focused on practicing frontend development by building a larger application from scratch, with an emphasis on clean UI, reusable components, dynamic data and JavaScript functionality.

## 🚧 Project Status

Currently in development.

### Completed
- Sidebar navigation
- Dashboard layout
- Dashboard cards and sections
- Spending Overview layout
- Income vs Expenses layout
- Recent Transactions layout
- Saving Goals layout
- Quick Actions layout

### Planned

- Dynamic transactions
- LocalStorage data persistence
- Loan Calculator

- ROI Calculator

- Dynamic Dashboard charts
